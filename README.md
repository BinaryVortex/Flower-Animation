# Flower Animation

A lightweight flower animation built with HTML, CSS, and JavaScript.

Preview

![Flower animation screenshot](Screenshot%202024-08-25%20144210.png)

About

This repository contains a small, self-contained web demo that renders an animated flower using modern CSS (and a bit of JavaScript where applicable). It's intended as a visual/creative experiment and a simple example you can study, tweak, and embed in your own pages.

Features

- Smooth CSS-driven animation
- Minimal, easy-to-read code (HTML + CSS + optional JS)
- Single-file demo (index.html) for quick testing

Live demo

- Open index.html in your browser to see the animation.
- You can also view the file on GitHub: https://github.com/BinaryVortex/Flower-Animation/blob/main/index.html

Run locally

1. Clone the repo:

   git clone https://github.com/BinaryVortex/Flower-Animation.git

2. Open the `index.html` file in your web browser (double-click or use a simple static server).

   Example with Python 3 built-in server:

   ```bash
   cd Flower-Animation
   python -m http.server 8000
   # then visit http://localhost:8000 in your browser
   ```

Files

- index.html — demo entry point (markup and any inline scripts)
- style.css — styling and animation rules
- Screenshot 2024-08-25 144210.png — preview screenshot used in this README

Customization

- Tweak colors, timing, and transforms in `style.css` to change the look and motion.
- If the demo uses JavaScript, you can modify behaviour in `index.html`.
